# MTPanel — پنل پروکسی عمومی تلگرام (MTProto) با تعویض IP و مدیریت تبلیغات

پنل وب دوزبانه (فارسی / English) برای اجرای پروکسی‌های عمومی MTProto با هسته‌ی **telemt** روی یک یا چند سرور.

## قابلیت‌ها
- **لینک‌ها**:
  - ساخت تکی یا گروهی
  - روشن/خاموش کردن با یک کلید
  - QR و کپی لینک
  - Secret جدید
  - انتخاب سرورهای هر لینک
- **تعویض IP با یک کلیک**: وقتی IP فیلتر شد، IP جدید را وارد می‌کنید و پنل ایجنت، لینک‌ها و DNS را به‌روز می‌کند. پنل همان لحظه چک می‌کند که سرور روی IP جدید جواب می‌دهد یا نه.
- **لینک ثابت با دامنه + Cloudflare**: با تعویض IP، رکورد DNS خودکار عوض می‌شود و **لینک‌های منتشرشده تغییر نمی‌کنند**.
- **صفحه‌ی عمومی**: یک آدرس با همه‌ی لینک‌های فعال و QR. همیشه به‌روز است.
- **تبلیغات (کانال اسپانسر)**:
  - تگ‌های اسم‌دار
  - کلید روشن/خاموش
  - تبلیغ اختصاصی برای هر سرور یا هر لینک
  - **تبلیغ زمان‌دار با برگشت خودکار**
  - نمایش اینکه الان روی هر سرور چه تبلیغی پخش می‌شود
- **جایگزینی سرور**: کد اتصال سرور جدید را در «ویرایش» سرور قبلی بچسبانید. لینک‌ها همان می‌مانند.
- **امنیت**:
  - پنل روی مسیر مخفی و با HTTPS اجرا می‌شود؛ کوکی Secure و HttpOnly است.
  - ارتباط پنل و نود از طریق TLS با گواهی پین‌شده و توکن انجام می‌شود.
  - API خود telemt فقط روی localhost است.
  - telemt با کاربر بدون دسترسی root اجرا می‌شود.

## زبان
- مراحل نصب در ترمینال انگلیسی است تا در همه‌ی ترمینال‌ها درست نمایش داده شود.
- پنل دوزبانه است: دکمه‌ی «English / فارسی» در صفحه‌ی ورود، بالای پنل و ویزارد. در حالت انگلیسی چیدمان چپ‌به‌راست می‌شود.
- زبان صفحه‌ی عمومی لینک‌ها جدا در **تنظیمات** انتخاب می‌شود.
- «کاربران آنلاین» = تعداد IP یکتا (تقریبی). هر برنامه‌ی تلگرام چند اتصال هم‌زمان باز می‌کند، برای همین «اتصال‌ها» همیشه بیشتر است.

## پیش‌نیاز
- VPS خارج از ایران با **Ubuntu 22.04 / 24.04** یا **Debian 12**، با دسترسی root.
- پورت‌ها را اسکریپت خودش انتخاب می‌کند:
  - پروکسی: 443، یا اگر اشغال باشد 8443 و…
  - ارتباط پنل با نود: 7443
  - پنل: 2053
- اسکریپت در پایان دقیقاً می‌گوید کدام پورت‌ها را در فایروال دیتاسنتر باز کنید.

## نصب
فایل را در `/root` سرور آپلود کنید، سپس:
```bash
cd /root
apt update && apt install -y unzip
unzip -o mtpanel.zip && cd mtpanel
bash install.sh
```
اول فقط دو گزینه نمایش داده می‌شود:
```
 1) Install main panel
 2) Install node (proxy server)
```
- **گزینه‌ی ۱، پنل اصلی:** فقط نام کاربری و رمز می‌پرسد. Enter یعنی `admin` و یک رمز تصادفی. در پایان آدرس پنل را نشان می‌دهد. با اولین ورود، **ویزارد راه‌اندازی** بقیه را مرحله‌به‌مرحله می‌پرسد:
  1. عنوان پنل
  2. افزودن سرور
  3. کانال اسپانسر
  4. Cloudflare
  5. دامنه و پورت پنل
- **گزینه‌ی ۲، نود:** هیچ سؤالی نمی‌پرسد. در پایان یک «کد اتصال» `mtpnode://…` می‌دهد که در پنل می‌چسبانید.
- پنل و نود از هم جدا هستند. اگر هر دو را روی یک سرور می‌خواهید، اسکریپت را دو بار اجرا کنید: یک بار گزینه‌ی ۱ و یک بار گزینه‌ی ۲.
- بعد از نصب، منوی مدیریت در هر جای سرور با دستور **`mtpanel`** باز می‌شود. گزینه‌های آن فقط برای چیزی نمایش داده می‌شوند که روی همان سرور نصب است:
  - به‌روزرسانی
  - نمایش کد اتصال
  - آدرس و پورت پنل
  - بازنشانی رمز
  - حذف

## دامنه، پورت و مسیر پنل (از داخل وب)
در **تنظیمات ← دسترسی پنل** یا مرحله‌ی آخر ویزارد:
- **گواهی معتبر:**
  1. یک ساب‌دامنه بسازید که رکورد A آن به IP سرور پنل اشاره کند. در Cloudflare ابر خاکستری باشد.
  2. دامنه را وارد کنید و «دریافت گواهی» را بزنید.
  3. پنل خودش از Let's Encrypt گواهی می‌گیرد و روی آدرس جدید بالا می‌آید. تمدید گواهی خودکار است.
  4. پورت 80 سرور باید باز باشد.
- **پورت و مسیر مخفی:** بعد از اعمال، پنل روی آدرس جدید بالا می‌آید و دوباره وارد می‌شوید.
- **اگر بعد از تغییر پورت پنل باز نشد:** روی سرور `mtpanel` را بزنید، گزینه‌ی «آدرس و پورت پنل» را انتخاب کنید و پورت را برگردانید.

## کانال اسپانسر
1. در **@MTProxybot** دستور `/newproxy` را بزنید. `IP:443` سرور را بفرستید و بعد Secret یک لینک را. Secret در منوی «⋯» لینک است و با یک کلیک کپی می‌شود.
2. Proxy tag را در تب **تبلیغات ← افزودن تگ** وارد کنید.
3. در ربات `/myproxies ← Set promotion` را بزنید و کانال را بدهید.
4. برای تست، با اکانتی که **عضو آن کانال نیست** وصل شوید.

> برچسب «اسپانسر فعال» روی کارت سرور یعنی سرور به Middle-Proxy تلگرام وصل است. اگر «غیرفعال» ماند، اتصال خروجی به **پورت 8888** تلگرام را تست کنید:
> ```bash
> timeout 5 bash -c '</dev/tcp/149.154.175.50/8888' && echo 8888-OK || echo 8888-BLOCKED
> ```
> اگر BLOCKED بود، دیتاسنتر این پورت را بسته است و باید از پشتیبانی بخواهید بازش کنند.

## تعویض IP (وقتی فیلتر شد)
1. از دیتاسنتر IP جدید بگیرید و روی همان سرور فعالش کنید.
2. در پنل، روی کارت سرور دکمه‌ی **🔄 تعویض IP** را بزنید و IP جدید را وارد کنید.
3. نتیجه بسته به تنظیمات سرور:
   - **سرور دامنه دارد و توکن Cloudflare تنظیم شده**: رکورد DNS خودکار عوض می‌شود و لینک‌ها ثابت می‌مانند.
   - **سرور دامنه ندارد**: لینک‌های آن سرور عوض می‌شوند. صفحه‌ی عمومی خودکار به‌روز می‌شود.

**تنظیم Cloudflare:**
1. یک API Token با قالب **Edit zone DNS** بسازید.
2. توکن را در **تنظیمات ← Cloudflare** وارد کنید.
3. برای هر سرور یک ساب‌دامنه (مثلاً `de1.example.com`) در «ویرایش سرور» بنویسید. رکورد باید **DNS only** باشد (ابر خاکستری).

## صفحه‌ی عمومی
آدرسش در تب لینک‌ها، دکمه‌ی «صفحه‌ی عمومی» است. به‌طور پیش‌فرض روی آدرس پنل است که گواهی خودامضا دارد.
برای آدرس تمیزتر می‌توانید یک ساب‌دامنه را با ابر **نارنجی** Cloudflare به IP پنل وصل کنید. در این حالت، SSL mode را در Cloudflare روی **Full** بگذارید. بعد در تنظیمات، «آدرس صفحه‌ی عمومی» را بنویسید، مثلاً `https://links.example.com:2053`.

## دستورات مفید
```bash
mtpanel                        # منوی مدیریت (بعد از نصب، از هر جای سرور)
mtpanel node-code              # نمایش دوباره‌ی کد اتصال نود
mtpanel reset-admin            # فراموشی رمز ادمین
mtpanel panel-address          # نمایش آدرس پنل / تغییر پورت
journalctl -u mtpanel -n 50 --no-pager        # لاگ پنل
journalctl -u telemt -n 50 --no-pager         # لاگ پروکسی
journalctl -u mtpanel-agent -n 50 --no-pager  # لاگ ایجنت
```

## به‌روزرسانی
فایل جدید را در `/root` بگذارید و بزنید:
```bash
cd /root && unzip -o mtpanel.zip && cd mtpanel && bash install.sh
```
گزینه‌ی «Install/Update main panel» یا «Update node» را انتخاب کنید. لینک‌ها و تنظیمات حفظ می‌شوند.

پیشرفته: اگر نود باید با مقادیر خاصی نصب شود:
```bash
MTP_NODE_PORT=443 MTP_NODE_TLS_DOMAIN=example.com bash install.sh node
```
